Amazon Clone Website

This is my **first project** in my programming journey, where I built a simple clone of the Amazon website using **HTML** and **CSS**.
The purpose of this project was to practice my front-end development skills by replicating the layout and design of a popular e-commerce site.

Features

**Homepage**: A mock-up of the Amazon homepage layout.
**Navigation**: A sticky navigation bar with a search bar and category links.
**Product Listings**: Display of product items with images, titles, and pricing.
**Footer**: A footer with links to various sections.

Technologies Used

**HTML5**
**CSS3**

Future Improvements

As this is my first project, I have a lot of room for growth. Some ideas for future improvements include:

-> Adding responsiveness for mobile devices.
-> Implementing JavaScript for interactive features like product filtering or a dynamic cart.
-> Integrating a backend system for user authentication and a checkout process.
